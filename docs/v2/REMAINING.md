# Remaining acceptance and production work

For the authoritative per-version/task states, use [the shared delivery checklist](../delivery/PROGRESS.md). This narrative preserves the outstanding V0.2 requirements; ENDSTATE reuse is additional tracked architecture work, not a reason to discard them.

This list distinguishes implemented developer functionality from outstanding proof. It is not permission to silently reduce the original PRD.

## Before calling the intelligence layer validated

Run a larger expert-labelled evaluation of extraction, explicit negation, contradictory sources, identity/authority, deadlines and missing dependencies. Measure semantic precision/recall, unsupported assertions, graph mistakes, abstention and operator correction time. Separate development fixtures from independent evaluation cases. The current tiny classifier configuration performed poorly; it must not be treated as a production decision engine. Jev remains untested without credentials.

The local graph adapter accepts a compact positive-effect draft with a mandatory final verification gate. Rich signed guards, resource assignments and contingencies are supported by the domain/editor, but are not all inferred by that small model. Do not claim that arbitrary situations become reliable plans without review. Dates in extraction still need operator resolution into scheduling constraints. Actor interests, authority and stance are not independently verified.

## Developer functionality still worth improving

Replace the advanced JSON editor for nested graph expressions with a fully guided graph authoring flow. Add model-assisted deduplication and reviewer-safe merging for repeated actors/claims without changing observed condition meanings. Improve long-source chunking and attribution beyond bounded excerpts. Add more responsive progress/cancellation for long local model requests, richer handling of stale proposals, and a complete keyboard/screen-reader audit. Extend the bounded scheduler only where measured cases justify it. Current estimates omit unknown waits and are not optimality proofs.

The source history and snapshots are replayable, but model-run records are a separate local log rather than an independently anchored audit. Case-local retrieval is lexical. Cross-case precedent retrieval and learning require a separate governance decision. Playbooks need domain-expert approval rather than more unreviewed templates.

## Production agency platform is the next milestone

Implement OIDC identity, organisations and matter membership, tested cross-tenant denial, scoped expert access, secure client accounts, encrypted evidence objects, malware scanning, immutable source hashes, retention/hold/deletion policies, revocation, external audit anchoring, backup restore rehearsals and observability. Design is recorded in `PRODUCTION-SECURITY.md`; these services are not deployed.

No autonomous email, calls, payment, tracking or external case actions are running. Do not add send capability until exact recipient/content/scope, human approval, expiry, idempotency and abuse tests exist. No public deployment or main merge is implied by this branch.
