## Emergence Review

**EM-339 — semantic JSON equality is not byte-identical challenge provenance.**
Canonical report serialization reorders nested objects. Reconstructing the
original challenge only from that ordering would falsely reject an otherwise
intact retained report. The reader verifies the raw content hash and semantic
equality, then uses the retained provider object's order with the same challenge
constructor. It does not repair malformed JSON or accept a mismatched input hash.
If omitted raw content and altered ordering prevent reconstruction, the typed
view stays withheld. Hashes remain local integrity references, not attestations.
