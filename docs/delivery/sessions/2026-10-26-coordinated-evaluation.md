Each original proposal is the single-model baseline. Jev, Clef Flash and GPT-6

## Execution and spending boundaries

Each method uses the real SQLite worker host with a fictional blank case,
scripted identities/grants, exact-source access policy, explicit source-processing
review and one queued attempt. These scripted reviews are not independent human
evaluation. Before/after case audit equality is checked. There is no graph commit,
chosen route, action send, observation or generated approval.

- At most four planning calls and three native decision calls per proposer;
  four proposers imply at most **28 requests** and **65,536 requested planning
  output tokens** (4,096 per planning call). No automatic retries/repairs/resume.
- Per method: 540 seconds; explicit host lease 600 seconds, not a changed default.
  Panel deadline 180 seconds. Existing host authority checks remain in force.
- Each decision panel stops at a US$0.025 reported-cost threshold (25 million
  nano-USD). Unknown/incomplete/failed/exhausted native challenge stops the whole
  remaining evaluation set, not just the current revision. Thresholds are
  checked after requests and can be overshot by the last request; they are not
  a provider-enforced billing cap. Planning charges are separate and unpriced
  under the owner's explicit bounded-token permission, not free or guaranteed
  to fit a dollar cap. No new pricing prerequisite or dashboard login is imposed.
- A planning-only failure is retained and may advance to the next **distinct**
  declared model. Authentication/authorisation failure stops later methods.
- Anthropic uses the existing medium effort/default thinking configuration;
  Experiential reasoning defaults are not overridden. Default high reasoning
  may consume the bounded response allowance; incomplete output is a failure,
  not permission to retry or weaken validation.
- Source mismatch is checked before every provider call and at closeout.
  An exclusive started marker prevents rerun/resume of the same frozen record.
- Safe protocol-specific receipts checkpoint after each attempted provider call.
  Request/response hashes, raw assistant JSON or validated native answers,
  served IDs, usage, known/unknown charge states and omissions are retained.
  No hidden reasoning, arbitrary native envelope or error-body retention.
  Transport-only evidence is not host publication. Persisted attempt counts
  are labelled **recorded**; a crash/write failure cannot prove no other charge.
