## Implementation and authority

ENDSTATE now derives a bounded information-check agenda from existing declared counter-links and scenario branches, keeping every statement and verification requirement. Display order is not expected value, urgency or predictive certainty. The 8BALL adapter projects the current case's linked questions and evidence-derived condition states alongside immutable briefs; neither viewing nor saving a brief writes to the case.

An explicit operator action supplies question, owner and reason. The existing validated case command transaction creates one open question, binds its provenance to the root and exact creation brief/contribution/revision, checks current snapshot/sequence/expiry, and clears action approvals. It does not answer, observe, select a course or send anything. Rechecks share a deterministic root/contribution key, preventing duplicate questions. Answers still require reviewed evidence; observations are separate, and source retraction restores effective uncertainty without erasing historical answers. Reconsideration appends a fresh brief and preserves original wording and earlier decisions.

The v1 rehearsal contract, replay and existing source-free exports are unchanged. No second scheduler/store, model call or upstream dependency. Check routes remain absent in agency configurations, where a separately authorised scoped projection is still required. Lock/case change clears protected UI state. Unsubmitted check fields survive review tab changes.
