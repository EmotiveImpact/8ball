### B03-05

`eightball/operations/journal.py` proposes three isolated tables with exact
organisation/matter/case keys. No Store constructor/router runs the migration.
Every read/command begins an immediate transaction, checks injected current authority,
verifies hash-linked history/snapshots/receipts, then rechecks authority before commit.
Request IDs are actor/scope bound; content conflicts and stale revisions fail. Cancelled
or closed records cannot be revived. Incident closure follows ordered investigation,
containment and resolution with evidence digests; no case fact or action is changed.

Revocation observations cover API/database/object-links/search/model-cache/workers.
Missing adapters yield unavailable; thrown adapters roll back with sanitized errors.
Closure reruns every surface and requires denied. This does not issue revocations or
establish remote transactional consistency. Actor identity is hashed in the journal;
constrained metadata/opaque handles/digests replace arbitrary sensitive narrative.

`api.py` exposes unmounted relative agency routes. `contracts.py` is the injection seam.
The verified host identity dependency plus transaction authority is mandatory; local
bearer possession is insufficient. Exact operations and integration steps are in README.

`recovery.py` signs exact original audit digests/scope/revision/head/time using maintained
Ed25519 primitives. Verification checks trust key, signature, timestamp age, scope,
revision and exact restored audit. A new 0600 sandbox is exclusively created; read-only
source SQLite backup, integrity/references and original audit/replay validators run.
Original alpha import/embedded lineage is tested. Cancellation/RTO failure preserves the
failed sandbox for deliberate inspection and never automatically retries or overwrites.

The copy is **whole database**, not tenant-filtered. Only explicitly supplied case
checkpoints are validated; no hidden data scan. Authority binding before signing,
managed key custody/rotation, remote independent anchoring, encryption, retention,
production restore, accepted SLOs and operational monitoring remain unimplemented.
The reported local RPO is checkpoint age, not measured backup/replication lag.
