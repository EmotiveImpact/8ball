# TencentDB Agent Memory: fit for ENDSTATE

16 October 2026. Inspected source at `e9a82935b52741e0c798c75326e90b7144eb4d5f`, native Git source-only clone. No dependencies installed, model calls, runtime tests, accuracy benchmark or integration.

Recommendation: shortlist a bounded, non-client project/team-knowledge experiment through the Core API/SDK. This is a procedural and conversational memory system, with Wiki/CodeGraph and versioned skills; compare retrieval against current source search before adoption. Graphiti remains a different candidate for temporal claim/relationship retrieval.

The root source licence is MIT. Standalone MemoryCore supports SQLite/files and BM25 without Tencent Cloud or external embeddings; extraction/consolidation still uses an OpenAI-compatible model. Full Hub/Proxy/Knowledge deployment is broader than this minimal experiment. Node 22+ and appropriate SQLite/FTS/native-module compatibility need testing.

Its L2 scenario is a scene/topic narrative, not a counterfactual world branch. It summarises/rewrites/merges memory; exact ENDSTATE source spans, unknown/disputed state, case revisions, selected courses and approvals must remain canonical in 8BALL. Generated skills remain proposed procedures until reviewed, not permissions or established successful methods.

Concrete JEV code already provides bounded choice selection with selected/none/unavailable outcomes and an optional persona-refresh gate. That is evidence of an implementation pattern, not evidence that JEV judges full routes correctly. Choice confidence is not calibrated success probability.

Proposed experiment: fixed public/fictional project decisions and documents; retrieve exact relevant sources; change/retract a source; separate two case/scenario scopes; compare direct search with Tencent memory, recording unsupported synthesis, missing citations, stale content, review effort, latency, model calls and cost. Freeze independent reference answers before final measurement. Gate any broader adoption on measured improvement and supported, tested operations.
