# Evaluation, ingestion and workflow candidates for ENDSTATE / 8BALL

Read-only source inspection, 2026-10-16. Source clones only; no dependencies installed, models downloaded, inference run, tests executed, or application files changed. Findings describe inspected implementations, not demonstrated interoperability or accuracy. Current application source was consulted at `/workspace/8ball`; it already has strict compilation, immutable evidence receipts, real-provider generation/journey runners, SQLite jobs, cancellation/stale guards and explicit human review. These should remain the acceptance baseline.

## Recommendation

Keep the current V0.2 pipeline and frozen fixtures. Add narrowly scoped adapters after V0.2 acceptance where a measured gap exists. The strongest near-term candidates are **Promptfoo as an optional developer-side model comparison tool** and **Docling as a later document ingestion worker**. Use one optional trace/review backend if the team actually needs a shared dashboard. Defer LangGraph/Temporal adoption until workflow complexity or operations justify migration. Combining all five would add duplicated state, dependencies and failure modes without establishing better decisions.

## Promptfoo: actual implementation and limits

- [Manifest](https://github.com/promptfoo/promptfoo/blob/132a2d38b1b0adc953b0db650f950d573bc113c4/package.json) declares MIT, v0.124.1, Node >=22.22.0. [License](https://github.com/promptfoo/promptfoo/blob/132a2d38b1b0adc953b0db650f950d573bc113c4/LICENSE).
- [Evaluator](https://github.com/promptfoo/promptfoo/blob/132a2d38b1b0adc953b0db650f950d573bc113c4/src/evaluator.ts#L1390) persists rendered raw prompt, response, latency, reported cost/incurred cost, metadata, test identity and trace linkage. It supports repeat groups, concurrency controls, abort signals and whole-evaluation timeout; these are execution aids, not our acceptance criteria.
- [Assertions](https://github.com/promptfoo/promptfoo/blob/132a2d38b1b0adc953b0db650f950d573bc113c4/src/assertions/index.ts#L259) include JSON, JavaScript, Python and LLM rubric assertions. Code assertions are executable trusted configuration; never treat imported case/source text as executable assertion code.
- [Cost assertion](https://github.com/promptfoo/promptfoo/blob/132a2d38b1b0adc953b0db650f950d573bc113c4/src/assertions/cost.ts) checks provider-reported cost **after** the response. It is not a hard pre-spend cap. Keep an application/provider budget controller and preflight upper bounds.
- [Telemetry](https://github.com/promptfoo/promptfoo/blob/132a2d38b1b0adc953b0db650f950d573bc113c4/src/telemetry.ts#L111) has `PROMPTFOO_DISABLE_TELEMETRY`. Prefer local results, explicit data egress configuration and no automatic share uploads for case material.
- Fit: source-to-plan regression comparison across authorized Qwen/DeepSeek/etc endpoints, prompt versions and repeated runs. It cannot make four known fixtures independent, make an LLM judge independent professional review, or prove outcome reliability.
- Cost/resource: Node development tool plus local results database/browser UI; actual models and rubric judges add inference cost. No new app production service needed if used only in evaluation.

## Phoenix: real traces/review data, with licensing boundary

- [Manifest](https://github.com/Arize-ai/phoenix/blob/2be380f7a360b7a71f97fc510de5e9679e58f7c9/pyproject.toml) and [license](https://github.com/Arize-ai/phoenix/blob/2be380f7a360b7a71f97fc510de5e9679e58f7c9/LICENSE) state Elastic-2.0. License prohibits providing the software as a hosted/managed service to third parties with access to a substantial set of its features. Avoid saying the whole platform is permissively open source based on README wording.
- [Database models](https://github.com/Arize-ai/phoenix/blob/2be380f7a360b7a71f97fc510de5e9679e58f7c9/src/phoenix/db/models.py#L1274) distinguish LLM, CODE and HUMAN annotations. Experiments bind dataset versions and repetitions; runs preserve output, trace identity, start/end time, token counts and error. [Experiment models](https://github.com/Arize-ai/phoenix/blob/2be380f7a360b7a71f97fc510de5e9679e58f7c9/src/phoenix/db/models.py#L1680).
- [Configuration](https://github.com/Arize-ai/phoenix/blob/2be380f7a360b7a71f97fc510de5e9679e58f7c9/src/phoenix/config.py#L170) supports SQLite and PostgreSQL; local default `phoenix.db`. It adds a service, storage/retention/backups and optional authentication operations.
- Fit: internal reviewer queues/datasets and common observability after there are enough real runs to warrant dashboard operations. Standard OpenTelemetry is a better long-term export seam than coupling ENDSTATE to a vendor UI.
- A record marked HUMAN does not prove identity, qualification, independence or signed acceptance. Our review protocol must preserve those separately.
- Prefer canonical append-only raw receipts in the project/evidence store even if traces are mirrored; deletable dashboards should not become the only acceptance evidence.

## LangGraph / Temporal: choose only when warranted

- LangGraph [manifest](https://github.com/langchain-ai/langgraph/blob/e77a5cb08c1f3ff306d997dd76fc7169afdab5ea/libs/langgraph/pyproject.toml) and [license](https://github.com/langchain-ai/langgraph/blob/e77a5cb08c1f3ff306d997dd76fc7169afdab5ea/LICENSE) are MIT. Actual [`interrupt`](https://github.com/langchain-ai/langgraph/blob/e77a5cb08c1f3ff306d997dd76fc7169afdab5ea/libs/langgraph/langgraph/types.py#L903) requires a checkpointer, exposes a human input request, and resumes by **re-executing the node from its start**. Non-idempotent writes inside such nodes can duplicate effects unless guarded. A workflow framework does not substitute for ENDSTATE expected-revision checks, authority expiry or evidence semantics.
- Temporal [manifest](https://github.com/temporalio/sdk-python/blob/346d4dcd0863657c3a33283c952a296762059339/pyproject.toml) and [SDK license](https://github.com/temporalio/sdk-python/blob/346d4dcd0863657c3a33283c952a296762059339/LICENSE) are MIT; adoption still needs an operated Temporal server or paid hosted service. [README](https://github.com/temporalio/sdk-python/blob/346d4dcd0863657c3a33283c952a296762059339/README.md#L729) requires deterministic workflow code; model/API calls belong in activities. [Cancellation modes](https://github.com/temporalio/sdk-python/blob/346d4dcd0863657c3a33283c952a296762059339/temporalio/workflow/_activities.py#L72) include TRY_CANCEL, WAIT_CANCELLATION_COMPLETED and ABANDON; [replayer](https://github.com/temporalio/sdk-python/blob/346d4dcd0863657c3a33283c952a296762059339/temporalio/worker/_replayer.py#L124) replays workflow history.
- Neither engine can recall an already-sent model request or external action. Cancellation means stopping future work and suppressing publication; actual resource cancellation depends on the provider protocol.
- Keep current jobs for V0.2. Future trigger for Temporal: multi-hour/day workflows, distributed workers, scheduled external-event handling, server restart recovery requiring durable history. Future trigger for LangGraph: complex conditional model stages or human resumptions where its checkpoint primitives simplify code. They can interoperate but adding both should require measured need.

## Docling: extraction utility, not evidence authority

- [Manifest](https://github.com/docling-project/docling/blob/f690a5232c505c787a1e952216b431134b4d7c94/pyproject.toml) defines modular `docling-slim` and optional format/model dependencies. [README licensing](https://github.com/docling-project/docling/blob/f690a5232c505c787a1e952216b431134b4d7c94/README.md#L151): MIT code, each model has its own license.
- Actual [reading-order stage](https://github.com/docling-project/docling/blob/f690a5232c505c787a1e952216b431134b4d7c94/docling/models/stages/reading_order/readingorder_model.py#L108) attaches page, bbox and character span to extracted text. These spans refer to extracted items; retaining original-file hashes and a mapping into 8BALL source spans is still our adapter's job.
- [Options](https://github.com/docling-project/docling/blob/f690a5232c505c787a1e952216b431134b4d7c94/docling/datamodel/pipeline_options.py#L1392) default remote services=false and external plugins=false. `artifacts_path=None` permits first-use model downloads; preconfigure approved local artifacts to prevent surprises. A timeout can return PARTIAL_SUCCESS; never turn that into silent full-document success.
- [Converter](https://github.com/docling-project/docling/blob/f690a5232c505c787a1e952216b431134b4d7c94/docling/document_converter.py#L632) exposes file/page size bounds; defaults are effectively unbounded, so the application must set them. PDF/OCR/layout processing can be CPU/memory intensive; GPU is pipeline-specific, not universally mandatory. Exact resource and model download size need profiling of the selected pipeline.
- Worker output is untrusted source material. Preserve original bytes/hash, parser/model version, extracted text, page coordinates, partial/error markers, and human correction history. Do not permit a document to choose tools, permissions, reviewer decisions or model system instructions. Docling does not solve prompt injection or semantic truth on its own.

## Shared experimental contract for the future combination

Before comparing a baseline plan to a swarm-generated scenario, freeze: case revision and source hashes; target and verification conditions; explicit assumptions; intervention/action; simulator/model/prompt versions; seeds where supported; requested repetitions; budget/time/round/token caps; uncertainty and abstention rules; evaluator identity/protocol. Store raw outputs, failures, cancelled/stale states and attempted calls rather than keeping only successful reports.

Compare at least: current ENDSTATE What If baseline; model-generated alternatives without swarm; swarm rehearsal plus the same plan generator. Otherwise any improvement cannot be attributed to the swarm. Use independently authored held-out cases and human adjudication, with useful failure discovery, missed constraints, false assumptions, review effort, latency and cost recorded. For probability forecasts, require defined event/horizon and out-of-sample calibration; simulated agreement or vote counts are not probabilities.

The current frozen four-case generation set remains unchanged and separately labeled as regression. Existing native tests and mock journeys remain engineering evidence. Neither Promptfoo, Phoenix nor a second model can confer independent professional or owner acceptance.

Suggested integration contract: `SourceArtifact -> ExtractionProposal -> ReviewedCaseRevision -> ScenarioRun -> DecisionAssessment -> HumanDecision -> EvidenceOfResult`. Preserve a separate hypothetical namespace; all live writes go through existing domain commands and expected-revision checks. Providers and simulators return proposals/assessments only. This makes adoption and replacement reversible and keeps the ENDSTATE engine reusable.
