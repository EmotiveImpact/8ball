# Bounded source assessment: semantic-router → 8BALL/ENDSTATE

## Verdict and evidence boundary

**Useful source of small advisory-routing patterns; not a replacement for ENDSTATE, its planner, Plan Review, Insights, Chosen Course, or the existing provider boundary. Prefer native adaptation before adopting the package.** Its “route” is an intent/category label, not an ENDSTATE course with prerequisites, evidence, authority, time and cost.

Inspected upstream commit **1fa1937e390fe57fb85ee3bbb8b3db593a4145db**, whose [package metadata declares 1.1.1](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/pyproject.toml#L1-L8), against exact 8BALL baseline **4f31c6b40141990d0863d9375f47a7ad51863dfc**. Statements below marked **Observed** describe source/control flow, not executed tests. **Inference/recommendation** describes potential transfer. Every experiment is **proposed and unrun**; its numbers are proposed decision criteria, not demonstrated quality.

Baseline already contains [detached deterministic calculation](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/api.py#L50-L63), [read-only plan inspection](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/plan_review.py#L1-L28), [isolated scenarios that clear approvals and do not persist](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/services.py#L32-L54), [typed structural Insights](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/insights.py#L1-L65), and [explicit revision/hash-bound Chosen Course selection](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/courses.py#L211-L263). The parent’s unpublished Assumption Challenge Brief is outside this baseline and was not inspected or validated.

## 1. Preserve a data-only advisory routing boundary; do not revive dynamic execution
**Recommendation: adapt native boundary; reject automatic tool/action execution.**

- **Observed upstream:** [Route](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/route.py#L6-L28) holds names, utterances, descriptions, thresholds and metadata; [RouteChoice](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/schema.py#L43-L50) returns an optional name/confidence/calibrated flag. The [v1 migration guide explicitly removes dynamic routes, function schemas, direct Route calls, RouteChoice.function_call, LLM wrappers and function-call helpers](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/docs/user-guide/guides/migration-to-v1.md#L323-L332). Its [replacement example puts subsequent invocation in application code](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/docs/user-guide/guides/migration-to-v1.md#L351-L373). [DecisionRouter forms a choice question from route descriptions or up to five utterances](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/decision.py#L43-L72).
- **Existing overlap:** [8BALL's provider module is advisory-only](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/providers.py#L1-L3); [provider-purpose/source validation](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/intelligence.py#L227-L261) precedes calls. The [command layer separately checks readiness, route support and approvals](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/commands.py#L142-L161). Chosen Course is a separate human intention record, not a dispatch label.
- **Transferable benefit—inference:** a small task-label suggestion could help an operator choose an already supported analysis purpose or provider from an allowlisted catalogue. A native envelope could retain proposed purpose, alternatives, abstention reason, source IDs, snapshot hash/revision and router-policy version. Nothing should be imported into the deterministic kernel merely to obtain this envelope.
- **Risks/limits/copy:** a label named “decision” is not a decision right; route descriptions are not trusted instructions. The current Jev adapter is event classification, not route criticism. Do not infer that new offered endpoints support the upstream protocol. MIT applies to copied code; removed legacy execution code is not an adoption target.
- **Proposed acceptance experiment:** use 100 fictional dispatch inputs, including unknown labels and instruction-like text, with fake providers only. Require 100% output labels to be allowlisted or abstain; zero tool invocations, case/observation/approval mutations or Chosen Course changes; and 100% suggestions bound to the supplied snapshot/policy version.

## 2. Make abstention explicit, and retain stronger native response validation
**Recommendation: adapt native abstention semantics; do not replace the current adapter with the generic router unchecked.**

- **Observed upstream:** [BaseRouter defaults its threshold to None](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/base.py#L74-L84). [_choose preserves raw-score ranking, accepts everything when no bar is set, and returns name=None only when no candidate passes](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/base.py#L112-L143). Per-call thresholds override route/router thresholds. [DecisionRouter._route_scores only checks for a probability dictionary, converts values with float, and fills missing route names with 0.0](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/decision.py#L59-L63); that function does not establish finite/range/sum/expected-key validity. [The calibrated flag can mean merely model.probabilistic, without fitting](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/base.py#L100-L110), via [the model flag assigned by DecisionRouter](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/decision.py#L37-L41).
- **Existing overlap:** [8BALL's Jev adapter checks numeric type, finiteness, range, exact label keys, distribution sum, selected-label consistency and response size](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/providers.py#L24-L61); it reports needs_review and abstains on unclear or confidence below 0.8. These checks are already stronger in important respects. Neither its 0.8 policy nor upstream defaults establish empirical calibration.
- **Transferable benefit—inference:** standardize an explicit no-match/manual-review result across optional providers, distinguishing raw similarity, provider-reported probability, empirical route-label calibration and unavailable/error. Policy should not let a caller silently lower safety thresholds.
- **Risks/limits/copy:** no threshold means no ordinary low-confidence rejection; a flag named calibrated can be misleading. A thresholded similarity score is not factual confidence, route success probability, authority or evidence. Raw retrieval scores need not sum to one, whereas a claimed categorical distribution needs its own strict contract. MIT notice required for copied implementation.
- **Proposed acceptance experiment:** a deterministic matrix of empty/unknown candidates, threshold ties, lower-ranked routes with different bars, and malformed claimed probabilities (NaN, infinity, booleans, strings, missing/extra keys, wrong sums). Require every malformed distribution to fail closed, every below-policy result to abstain, and zero unauthorized threshold downgrades. This tests the contract, not model quality.

## 3. Borrow held-out routing evaluation, not “decision quality” probabilities
**Recommendation: adapt evaluation design natively; defer calibrated UI claims until domain-specific evidence exists.**

- **Observed upstream:** [afit learns from the top raw score and whether its label is correct, including None labels for out-of-scope queries; FitReport ECE is calculated on that same fitting data](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/base.py#L150-L173). [Calibrator requires both correct and incorrect examples and supports Platt/isotonic maps](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/calibration.py#L1-L35). The [benchmark specifies CLINC150 intent routing and separate validation/test data](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/benchmarks/accuracy.py#L1-L16). Its [measurement code fits on validation, evaluates held-out test, measures in-scope accuracy, out-of-scope recall, ECE and a threshold curve, and tunes a threshold on validation](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/benchmarks/accuracy.py#L238-L271).
- **Existing overlap:** [the product explicitly distinguishes evidence, unknowns, human commitments and fabricated probabilities](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/docs/PRD.md#L87-L95); [Plan Review is provider-free structural review, not approval](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/docs/v2/PLAN-REVIEW.md#L25-L35). Existing deterministic diagnostics cannot be replaced by an intent benchmark.
- **Transferable benefit—inference:** evaluate a narrowly specified routing task using operator-labelled fictional examples, out-of-scope cases, ambiguity/negation and scenario-family-disjoint splits. Report accepted-route precision, coverage/abstention, OOS false acceptance, per-label errors, latency/cost and calibration provenance—not just aggregate accuracy.
- **Risks/limits/copy:** fitting-set ECE is not held-out validation. A map fitted on top predictions is also applied by [_probs to every route score](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/base.py#L104-L110); lower-ranked per-route probabilities therefore need separate validation. Catalogue/model/corpus drift invalidates old calibration assumptions. Public intent performance says nothing about omitted dependencies, source truth, authority, professional judgement or outcome success. MIT code permission does not clear benchmark datasets or model weights.
- **Proposed acceptance experiment:** pre-register a fictional routing corpus with separate exemplar, calibration and held-out scenario families and at least 25% OOS examples in the last two sets. Select thresholds only on calibration. Keep a candidate only if held-out accepted-route precision and OOS rejection each reach 95%, and it improves coverage over a keyword-only baseline at those same constraints. Publish counts, confidence intervals and per-label failures; do not rebrand this as plan-quality acceptance.

## 4. Adapt a budgeted cascade, but do not inherit composition's confidence semantics
**Recommendation: adapt a bounded native cascade only if useful; reject pooled scores as corroboration.**

- **Observed upstream:** [Chain sends only unresolved queries to later routers](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/compose.py#L39-L64). However, its final child returns scores regardless of that child's bar (line 55); the eventual outer choice uses [BaseRouter's threshold logic](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/base.py#L112-L143) and [the first child's route catalogue exposed by Chain](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/compose.py#L23-L34). Thus the last child's threshold is not automatically the final abstention rule. [Merge asks every child concurrently, averages scores with weights, and treats missing route scores as zero](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/compose.py#L67-L112). Its calibrated flag is simply all(child.calibrated).
- **Existing overlap:** [analysis submission is revision-bound, queue-limited and idempotency-aware](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/analysis_jobs.py#L138-L177); [cancellation/stale-work handling](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/analysis_jobs.py#L184-L210) already distinguishes stopping publication from recalling an in-flight call.
- **Transferable benefit—inference:** deterministic eligibility checks first, an optional cheap local suggestion second, then at most an explicitly authorized bounded provider stage. The wrapper should impose one end-to-end call/cost/time budget, preserve each stage's provenance and dissent, and allow no result.
- **Risks/limits/copy:** child thresholds are not compositional safety proofs. Mixed raw/calibrated scores are not comparable by default; even empirically calibrated children do not make a weighted mean empirically calibrated. Same-model agreement is not independent evidence. Merge increases all-provider data disclosure/cost, and no route selection can bypass explicit provider permission or choose/alter the human course. MIT permits adaptation, not reliance on statistical independence.
- **Proposed acceptance experiment:** with fake routers/transports, exercise a 100-request matrix covering last-stage low scores, conflicting route thresholds, disagreement, timeout, cancellation and budget exhaustion. Require final abstention below the declared final policy, no more than the authorized total attempts including retries, zero external attempts without destination/data consent, preserved individual disagreements, and zero stale publication.

## 5. Treat dense+sparse “hybrid” as retrieval scoring—not deterministic policy checking
**Recommendation: candidate component for bounded retrieval/triage experiments; reject it as an authority or evidence validator.**

- **Observed upstream:** [IndexedRouter exposes alpha, top_k and mean/max/sum aggregation](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/indexed.py#L87-L109); [_query scales dense and sparse query components and aggregates returned utterance scores by route](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/indexed.py#L215-L238). [HybridLocalIndex adds dense and sparse similarity scores; it explicitly rejects route_filter](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/index/hybrid_local.py#L104-L133). This is not an exact-rule/semantic guardrail conjunction.
- **Existing overlap:** [ENDSTATE's inspection rubric already asks about sources, dependencies and authority](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/plan_review.py#L15-L27), and [8BALL validates provider-purpose compatibility, selected sources and retractions before analysis](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/intelligence.py#L227-L261). [Insights explicitly distinguishes structural findings, correlated sources and hypotheses](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/insights.py#L16-L29).
- **Transferable benefit—inference:** sparse terms may complement semantic paraphrases when suggesting a bounded analysis category or retrieving relevant candidate excerpts. Exact current-revision, source-membership, identifier, permission and policy checks must remain separate native vetoes. Any future retrieval suggestion must retain original excerpt IDs and exact spans, not replace evidence with vectors.
- **Risks/limits/copy:** high lexical or embedding similarity can miss negation, changed dates, distinct same-name people and missing dependencies. Summed/mean scores and top_k composition can change when exemplars change. Sparse matching is not an exact constraint, and a local index lacking filtering is not a multi-client boundary. No entity merging, fact attestation or cross-client learning. MIT source rights do not cover an encoder's model/dataset terms.
- **Proposed acceptance experiment:** on 80 fictional paraphrase/identifier/negation/date-conflict cases, compare lexical-only, dense-only and hybrid top-3 retrieval with human-labelled relevance. Require hybrid to improve relevant-item recall by at least 10 percentage points over lexical-only without increasing false matches; require native negative authorization/source-scope controls to reject 100% of prohibited cases irrespective of score. Otherwise defer the added complexity.

## 6. Make catalogue/calibrator changes explicit and snapshot-bound; avoid mutable shared-index policy
**Recommendation: adapt immutable provenance/invalidation; defer mutable remote route catalogues and automatic refitting.**

- **Observed upstream:** [the index is IndexedRouter's source of routes; refresh updates its cache, but newly written index hits can affect queries immediately](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/indexed.py#L126-L175). An uncached route uses the router-wide threshold rather than its not-yet-loaded route threshold. [Adding a route with a fitted sparse encoder refits vocabulary and deletes/rebuilds the index](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/indexed.py#L196-L206). [add/remove invokes _refit; saved fitting queries are rescored, or calibration is dropped when they are unavailable](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/base.py#L178-L227). In contrast, [_fill/refresh only changes the cache](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/indexed.py#L144-L161), not the fitted calibrator.
- **Existing overlap:** [Chosen Course records exact case revision/hash, predecessor and request hashes, and requires an explicit acknowledged replacement](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/courses.py#L221-L263). [Plan Review binds assessment/sequence/revision and explicitly records execution_authorised=False and facts_attested=False](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/plan_review.py#L128-L174). These are better patterns for audit-relevant routing than live shared-index mutation.
- **Transferable benefit—inference:** give a candidate router an immutable versioned manifest covering route labels/examples, encoder/model identity, index snapshot, scoring/threshold policy and calibrator plus labelled evaluation provenance. Bind every suggestion to this manifest and the live case hash/revision. Catalogue edits should produce a new reviewed version, not silently change existing outputs.
- **Risks/limits/copy:** out-of-band changes can introduce unapproved labels or stale thresholds/calibration. Auto-refit can replay sensitive inputs and generate paid requests; rebuilding a shared index is not a safe live transaction. A loaded calibrator may disappear after edits, changing score meaning. Retain dissent and old results; never use another client's examples. MIT allows copying mechanics, but these lifecycle semantics should not be copied wholesale.
- **Proposed acceptance experiment:** 20 deterministic fake-index scenarios covering external writes before refresh, threshold edits, route removal, vocabulary rebuild and loaded-calibrator mutation. Require every changed artifact to change the manifest hash, all stale/unknown-catalogue results to be rejected, zero automatic provider requests on configuration edits, and zero cross-case lookup. Keep prior records immutable.

## 7. Account for all egress and dependency surfaces—not only the final provider call
**Recommendation: adapt native egress receipts and explicit budgets; defer package/hosted-index adoption pending a demonstrated need and separate approvals.**

- **Observed upstream:** [OpenAIEncoder sends docs to embeddings.create and may truncate first](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/encoders/openai.py#L102-L126). [PineconeRecord includes the original utterance in metadata even though its ID hashes that utterance](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/index/pinecone.py#L80-L115), then [upserts records](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/index/pinecone.py#L521-L536). [SystemOne posts state, model and questions; defaults include three retries and concurrency eight](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/decision_models/systemone.py#L20-L104). These are distinct disclosure/cost surfaces.
- **Observed configuration/dependencies:** [from_config constructs encoders/indexes and supplies routes for upsert](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/config.py#L321-L355); [IndexedRouter construction builds and refreshes the index synchronously](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/routers/indexed.py#L117-L124). Thus loading is not merely reading inert settings. [FastEmbedEncoder constructs TextEmbedding](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/encoders/fastembed.py#L20-L53); actual model acquisition/offline behavior is in a dependency not audited here. [Core dependencies include several hosted-provider SDKs, with additional local/index/provider extras](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/pyproject.toml#L9-L74). API-key fields are excluded from [the SystemOne model representation/serialization](https://github.com/aurelio-labs/semantic-router/blob/1fa1937e390fe57fb85ee3bbb8b3db593a4145db/semantic_router/decision_models/systemone.py#L34-L53), which is useful but not consent or data minimization.
- **Existing overlap:** [8BALL requires explicit external permission and server-owned keys](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/providers.py#L30-L40), uses a [controlled HTTP client](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/providers.py#L63-L68), and [validates selected sources, retractions, purpose and input limits](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/intelligence.py#L227-L261). Retain these boundaries instead of replacing them with environment-based upstream auto-configuration.
- **Transferable benefit—inference:** an application-owned egress manifest should cover encoding of exemplars and queries, remote-index writes, decision requests, calibration/refit/evaluation and retries. Allowlisted destination/model, exact source scope, purpose, byte/token limits, retention assumptions and cancellation semantics must be explicit before any transmission.
- **Risks/limits/copy:** a hashed record ID does not anonymize stored plaintext. “Local index” does not imply local encoding; “local encoder” does not prove offline initialization. Hosted retention, service terms, endpoint/model compatibility and actual latency/quality remain unknown. MIT is not a privacy agreement or permission to upload client data; transitive packages/models/services need separate review.
- **Proposed acceptance experiment:** with fake transports and constructors, trace load/build/add/fit/evaluate/query paths. Require 100% of attempted transmissions to pass the native purpose/destination/source-scope/budget gate first; zero unauthorized transmissions, cross-case records or secret-bearing exports; and complete receipts for every permitted attempt, including retries. This can precede any separately authorized live experiment.

## Integration recommendations

1. Keep 8BALL as the fixer product and ENDSTATE as the deterministic typed-contract/calculation kernel. Do not add semantic-router imports, network access, provider selection authority, model weights or mutable indexes to ENDSTATE.
2. Most promising native transfers: an advisory task-label/abstention envelope; strict probability-vs-score typing; held-out routing evaluation with OOS cases; explicit budgeted cascade policy; and immutable catalogue/calibrator provenance. These are candidates, not accepted requirements.
3. Suggested future boundary: operator requests an existing analysis purpose and source scope → native eligibility/revision/permission checks → optional local routing suggestion → explicit destination/purpose authorization (or an already approved bounded policy) → existing analysis-job/provider path → strict response validation → reviewable proposal → human command. No automatic switch of Chosen Course, evidence state, approvals or case facts.
4. A hosted decision router may only be a bounded optional provider adapter after verified provider/model identity, explicit permission, contract/egress tests and independent purpose-specific evaluation. The current Jev implementation is event classification; do not call it route criticism. Upstream model names/default URLs do not verify any newly offered endpoint.
5. Candidate component only after measurement: local dense/sparse retrieval or task-intent indexing with exact source IDs/spans and native hard gates outside scoring. Defer full package adoption, remote shared indexes, mutable route metadata and auto-refit. The dependency and lifecycle footprint exceeds what is needed for a simple advisory envelope.
6. Reject: resurrected dynamic-function execution, thresholded similarity as evidence/authority, calibrated flags as proof of calibration, intent correctness as plan success, weighted agreement as independent corroboration, cross-client learning, or silent external retries/calls. Maintain manual and no-match fallbacks.
7. Parent owns archival copies, canonical decisions, task IDs and emergence records. No application edits/commits/PRs or canonical-status changes were made; no runtime adoption or scope expansion is implied.
