# HighwayEnv: bounded transfer review

**Comparison baseline:** 8BALL/ENDSTATE at `4f31c6b40141990d0863d9375f47a7ad51863dfc`, not the local checkout's later HEAD. **Verdict:** adapt a few native contract and test patterns; do not adopt HighwayEnv as an ENDSTATE runtime component. Its [stated scope](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/README.md#L18-L20) is autonomous-driving environments, not social or general-world prediction. No demonstrated product benefit follows from preserving its source.

The seven findings below distinguish observed code from proposed transfer. All acceptance experiments are **future proposals, not executed tests**. Each assumes synthetic application-owned fixtures and existing human-commit boundaries. **Common licensing condition for every finding:** HighwayEnv's [MIT license](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/LICENSE#L1-L22) permits source reuse subject to notice retention; recommendations below are native design/test adaptations with no upstream dependency or source copy required.

## 1. Explicit observation projections, separate from the full state and action contract

**Observed evidence.** [define_spaces](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L156-L163) builds action and observation types separately. [ObservationType](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/observation.py#L31-L55) separates space declaration, observation generation and observer identity. [KinematicsObservation configuration and projection](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/observation.py#L175-L285) selects features, bounds vehicle count, normalizes/clips, orders/pads and optionally shuffles observations. These are simulator-owned projections, not truth acquisition.

**Existing overlap.** ENDSTATE already has [versioned detached PlanRequest/PlanResponse contracts](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/api.py#L18-L63) and [typed provenance, source spans and unknown/true/false/disputed states](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/contracts.py#L11-L37). Do not describe those as missing.

**Transferable benefit — inference.** A future assumption-critique view can explicitly declare which case references, epistemic labels and fields are visible, keeping the complete snapshot separate from the bounded report/proposal. This makes information loss inspectable.

**Risk/limit.** A fixed-size observation can silently omit records; absence from a projection must never become false, and simulator-provided intentions must not become asserted knowledge of real people. Numeric clipping/normalization is inappropriate for evidence state, signed predicates or authority. Representation validity is not factual validity.

**Recommendation:** **adapt native**, using existing Pydantic contracts; reject Gymnasium spaces as a replacement for ENDSTATE's provenance-rich contract.

**Acceptance experiment:** one fixture matrix containing observed, claim-only, unknown, disputed and hypothetical conditions. Project each through the proposed bounded view and validate outputs: 100% of included conditions retain state/provenance/reference identity; omitted items remain explicitly unobserved; zero facts, approvals or effects are created. Invalid or cross-case references must be rejected.

## 2. Reproducible reset/replay manifests rather than a seed-only claim

**Observed evidence.** [reset](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L221-L251) accepts seed/options, delegates seeding to Gymnasium, optionally changes config, rebuilds the scene and resets time/steps. [step and simulation cadence](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L261-L319) distinguish policy decisions from simulation frames. [paired action tests](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/tests/envs/test_actions.py#L43-L67) reset variants with seed=0 and compare equivalent action trajectories.

**Existing overlap.** ENDSTATE [calculate](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/api.py#L18-L63) already takes an explicit aware as_of clock and detached snapshot/revision. [inspect_plan](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/plan_review.py#L129-L159) records assumptions and uses explicit clocks; [its determinism test](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/tests/test_plan_review.py#L26-L33) already compares repeated calls. By contrast, application [simulate](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/services.py#L15-L54) reads utcnow internally and constructs hypothetical records; raw byte-identical replay should not be assumed for every adapter.

**Transferable benefit — inference.** For derived comparisons, retain a replay envelope: snapshot hash/revision, as_of, contract/rule version, ordered overlay specifications, input references and output hash. Record a seed only if randomness actually exists; do not add randomness to a deterministic core merely to imitate an environment.

**Risk/limit.** A seed does not identify source revision, configuration, action sequence or every random generator. Config carried over on reset also matters. Simulator time is not real-world waiting time; advancing a hypothetical clock cannot satisfy an external wait or create observations.

**Recommendation:** **adapt native** around the explicit-clock inspection path; defer any stochastic harness or worker runtime.

**Acceptance experiment:** replay one fixed snapshot/as_of/overlay manifest 20 times through inspect_plan: require identical canonical results and unchanged snapshot hash. Changing revision, as_of or an overlay must produce a distinct manifest or explicit stale-input rejection, never reuse a result under the old identity.

## 3. Isolate scenario branches AND verify the exact changed set

**Observed evidence.** [deep-copy preprocessors](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L380-L452) transform copied environments; [custom deepcopy](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L457-L467) excludes viewer/video wrappers. However, [set_vehicle_field](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L431-L437) iterates cloned vehicles while comparing identity with the original self.vehicle. Static inference: that guard does not exclude the cloned ego vehicle as its shape suggests. [set_preferred_lane](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L414-L422) uses a truthiness guard, making lane 0 a no-op. These were not runtime-reproduced. The [preprocessor smoke test](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/tests/envs/test_env_preprocessors.py#L9-L26) resets after transformations, then checks observation/reward bounds; it does not assert transform targeting or persistence.

**Existing overlap.** [inspect_plan](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/plan_review.py#L129-L159) already clears scenario approvals, runs up to three independent hypothetical scenarios and denies semantic/execution authority. [simulate](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/services.py#L15-L54) checks revision, clones data and returns persisted=false. [existing tests](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/tests/test_plan_review.py#L62-L99) cover isolation, nonaccumulation, zero budget, invalid specs and scenario limits.

**Transferable benefit — inference.** Strengthen exact-target assertions, not just deep-copy assertions: allowlisted changes by stable ID, explicit zero-versus-omitted handling, independent baselines and declared approval removal.

**Risk/limit.** An unchanged original does not prove the copy changed the right object. Arbitrary attribute/method/class-path transforms are not suitable operator-supplied scenario APIs.

**Recommendation:** **adapt native tests**, not HighwayEnv's copy helpers; retain current <=3 scenario limit rather than create another simulator.

**Acceptance experiment:** run three declared overlays independently and in reversed order. Require identical per-overlay results, unchanged live case hash/revision/observations/approvals/selected course, no case-audit writes, and a changed-field set containing only the declared overlay plus the explicitly intended removal of scenario approvals. Include zero budget and missing/completed/disabled action cases. A separate explicit save may append a derived report, never mutate case facts.

## 4. Keep bounded computation distinct from evidenced outcomes

**Observed evidence.** [step](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L261-L287) returns terminated and truncated separately. In [HighwayEnv](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/highway_env.py#L141-L151), termination is collision/optional off-road status; truncation is elapsed duration. Important counterexample: [finite_mdp conversion](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/finite_mdp.py#L85-L97) combines collision and end-of-horizon in a single terminal array. The distinction can be lost in an adapter even when the outer API has it.

**Existing overlap.** ENDSTATE already exposes [search_truncated, expansions and explicit search limits](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/planner.py#L314-L318); it does not equate bounded search with proof of no solution. [epistemic states](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/contracts.py#L11-L11) and [Plan Review's non-authority result](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/plan_review.py#L154-L159) remain separate.

**Transferable benefit — inference.** Preserve separate fields for search exhaustion, hypothetical time cutoff, unresolved external waits and evidence-backed outcome state across every report/adapter. The UI must distinguish 'not found within this search' from 'false' and from 'verified complete'.

**Risk/limit.** A Gym termination flag can mean failure, not success. The driving finite-MDP terminal model is not an ENDSTATE truth model; no automatic closure, approval or failure assertion should follow a stop flag.

**Recommendation:** **adapt native** reporting/regression checks on existing fields; **reject** the finite-MDP terminal abstraction for case outcomes.

**Acceptance experiment:** a fixture matrix reaches a search bound, an unresolved external wait, a hypothetical deadline cutoff and a genuinely evidenced objective. Require distinguishable statuses in every serialized report; only the last may report outcome_evidenced=true, and none may independently close the case or grant authority.

## 5. Action catalogue, current eligibility and authority are different contracts

**Observed evidence.** [ActionType](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/action.py#L23-L70) separates space declaration, execution and available actions. [DiscreteMetaAction.get_available_actions](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/action.py#L264-L300) filters lane changes by reachability and speed changes by speed index. This is a physical eligibility projection, not permission or legal authority.

**Existing overlap.** 8BALL already separates [approve and complete handling](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/eightball/v2/commands.py#L142-L155), checks current readiness, compatible routes and approval expiry. [Chosen Course reassessment](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/course.py#L115-L135) validates case/revision/clock continuity and [preserves the selected prerequisite branch](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/course.py#L213-L223); recomputation is not a new selection.

**Transferable benefit — inference.** Any scenario/action view should expose separate explanations for catalogue membership, structural eligibility, evidence sufficiency, human selection and authority. Reuse readiness and command validation rather than create a second eligibility engine.

**Risk/limit.** Hiding an action in a UI is not enforcement; displaying it is not authorization. The simulator's execute-action abstraction is explicitly unsuitable for real-world automatic execution. A simulated prerequisite or fictional perspective cannot grant permission.

**Recommendation:** **adapt native** explanatory projections; **reject** any availability-to-approval or route-selection-to-execution shortcut.

**Acceptance experiment:** test actions that are structurally blocked, approval-required, approved-but-expired and validly approved at the current revision. Attempt corresponding local fixture commands through the existing validation boundary: require 100% rejection of unauthorized completions, correct reason labels, and zero approvals caused by scenario evaluation, sorting or course selection. No external action is part of the experiment.

## 6. Preserve diagnostic dimensions; do not turn a reward into confidence

**Observed evidence.** [HighwayEnv reward calculation](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/highway_env.py#L100-L139) derives component rewards, then weights/normalizes them. [reward documentation](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/docs/rewards/index.md#L3-L12) explicitly avoids specifying every desirable driving behavior. [finite_mdp's description](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/finite_mdp.py#L20-L42) calls TTC cells collision probabilities under constant-speed/no-other-lane-change assumptions, while [the implementation](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/finite_mdp.py#L125-L161) assigns hard-coded 1 and 0.5 collision-point costs. No empirical calibration evidence was established by this inspection.

**Existing overlap.** ENDSTATE already reports route dimensions, evidence gaps, waits and limits rather than a guaranteed outcome; [planner result construction](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/planner.py#L270-L318) retains route identities and explicit limits. [Plan Review](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/plan_review.py#L129-L159) compares hypothetical constraint compatibility and denies semantic certification.

**Transferable benefit — inference.** Use dimension-level scenario deltas: hard breaches, evidence gaps, unknown waits, resources, costs and route membership, with exact assumptions and retained objections. Ranking is a preference presentation, not a factual or normative conclusion.

**Risk/limit.** A 0–1 reward is not a success probability; a weighted sum can compensate for a hard constraint and hide dissent. Driving lane/speed/collision weights have no justified mapping to a fixer workflow. Multiple outputs from a shared model are not independent corroboration.

**Recommendation:** **adapt native** component diagnostics; **reject** driving rewards, TTC social predictions and invented confidence/success percentages.

**Acceptance experiment:** compare the same fixture under two permitted route sort orders and one explicit budget overlay. Require an inspectable component delta, unchanged evidence/authority states and unchanged selected course; hard breaches may never disappear through weighting. Require zero probability claims unless supported by a separately specified, independently evaluated calibration method—which is outside this task.

## 7. Differential contract tests plus explicit fidelity labels

**Observed evidence.** [Gym API tests](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/tests/envs/test_gym.py#L49-L106) check API shape, observation-space membership, reset config and terminated/truncated behavior. [action tests](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/tests/envs/test_actions.py#L43-L67) compare seeded equivalent action configurations; [observation regressions](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/tests/envs/test_observations.py#L23-L64) check declared shape/space behavior. [timing tests](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/tests/envs/test_time.py#L18-L39) measure throughput, not semantic quality. [HighwayEnvFast](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/highway_env.py#L154-L182) changes frequency, scene size and collision checking; [simplify](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L380-L395) removes distant vehicles with a stated intent to preserve optimal actions, not a proof of equivalence.

**Existing overlap.** The [Plan Quality Gate](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/evals/PLAN-QUALITY-GATE.md#L5-L23) already separates software behavior, actual inference and independent semantic evaluation. [Plan Review tests](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/tests/test_plan_review.py#L26-L99) already cover determinism, truth/effect boundaries, independent scenarios and invalid inputs.

**Transferable benefit — inference.** Add focused differential tests across existing adapters/reports using the same snapshot, clock, sort order and engine version; record approximation/fidelity differences if any are later introduced. Preserve source-bound failure artifacts.

**Risk/limit.** API compatibility, throughput and seeded agreement do not prove good judgement or real-world predictiveness. Removing 'irrelevant' records may remove external dependencies or authorities. Treat fast/simplified modes as different models unless equivalence is demonstrated.

**Recommendation:** **adapt native tests**; **defer** approximation/optimization components and any stochastic evaluation infrastructure.

**Acceptance experiment:** a fixed offline fixture pack covering unknown/disputed evidence, unproved effects, approval expiry, negative predicates, independent overlays and search limits. Compare canonical shared result fields from existing calculation/review adapters: zero unexplained semantic differences; every intentional difference documented. Record source hash, input/manifest hash, clock, result hash and failure category. Keep structural pass, performance and independent human semantic judgement as separate unfilled-or-measured columns; do not infer a quality pass from the first two.

## Integration recommendations

1. **Adapt native, highest priority if the owner elects work:** strengthen exact-target scenario regression tests (finding 3), preserve stop/outcome distinctions through every adapter (4), and formalize replay provenance using the existing explicit-clock calculation/review contracts (2). These are bounded improvements to existing behavior, not authorization for a new subsystem.
2. **Adapt native only as needed:** provenance-preserving projection contracts (1), eligibility/authority explanations backed by current readiness checks (5), dimension-level deltas with retained objections (6), and differential/fidelity tests (7). Start by extending existing tests; the baseline already implements these principles substantially.
3. **No direct candidate runtime component is recommended.** Reject importing HighwayEnv, Gymnasium, driving rewards, TTC/finite-MDP dynamics, autonomous-driving policies or arbitrary class/method/attribute configuration into ENDSTATE. The additional dependencies and domain assumptions buy little over existing typed Python contracts.
4. **Defer** Monte Carlo/stochastic workers, a new simulator, automatic multi-agent deliberation, approximation modes and model/provider work. Nothing inspected establishes their necessity or benefit for the fixer product.
5. If the parent's reported Assumption Challenge Brief proceeds, apply these only as candidate acceptance criteria: explicit snapshot/hash/revision/clock, <=3 independently applied typed overlays, immutable derived records, retained dissent, and no promotions from hypothetical to factual/authorized state. The reported <=4 perspectives/<=12 contributions are user-supplied design constraints, not inspected HighwayEnv features or validated application implementation. Do not introduce named-person psychological prediction or shared-model-vote confidence.
6. Preserve 8BALL as the flagship and ENDSTATE as the deterministic core. Source claims, observations, unknowns, assumptions, selected courses, approvals, completions and evidenced effects remain different records, consistent with [product invariants](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/docs/PRD.md#L87-L95) and [runtime architecture](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/docs/architecture/ENDSTATE-SYSTEM.md#L5-L15). Parent/owner must make adoption decisions and map any accepted item into canonical records; this report creates no required scope, canonical task ID, PR or implementation acceptance.

## Emergence findings

These are source-review discoveries, not build/runtime discoveries. Suggested dispositions are for the parent to decide; none is silently promoted into scope.

- **Existing capability is the starting point — existing-task strengthening/no duplicate engine.** ENDSTATE already has explicit-clock detached calculations, independent typed scenarios, authority stripping, structural Insights and fixed-course reassessment. [Scenario and determinism tests](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/tests/test_plan_review.py#L26-L99) demonstrate what the source intends to assert, not a test result from this session. The useful delta is more exact validation and provenance, not 'add simulation'.
- **Isolation is weaker than correct targeting — new candidate regression criterion.** [set_vehicle_field](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L431-L437) compares cloned objects to the original vehicle; [lane-zero guard](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L414-L422) silently skips zero. The [test resets before its assertions](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/tests/envs/test_env_preprocessors.py#L9-L26). Static inference: copy immutability/API smoke checks can miss changed-object and zero-value errors. Exact touched-set and post-transform assertions matter; do not transplant these helpers.
- **Adapters can erase distinctions the main API preserves — new candidate serialization criterion.** [Gym termination/truncation](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/highway_env.py#L141-L151) is explicit, but [finite_mdp](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/finite_mdp.py#L85-L90) ORs collision with horizon exhaustion. Reject that compression for outcome evidence; preserve search-limit/unknown/verified distinctions end-to-end.
- **Probability-shaped numbers are not calibration — reject transfer/decision record.** [TTC probability wording and assumptions](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/finite_mdp.py#L20-L42) coexist with [hard-coded collision-point costs](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/finite_mdp.py#L125-L161). No calibrated social/fixer probability follows. Keep diagnostic dimensions, explicit assumptions and dissent; reject imported driving rewards and fabricated success confidence.
- **Speed can mean a changed model, not merely faster execution — defer.** [HighwayEnvFast](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/highway_env.py#L154-L182) alters frequency, scene size and collision checks; [simplify](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L380-L395) removes distant vehicles. Its optimal-action-preservation comment is an intention, not demonstrated equivalence. Any future ENDSTATE pruning must preserve selected dependency branches, evidence and authority or disclose a different fidelity level; no optimization work is justified here.
- **A research simulator's extension surface is not an operator-safe contract — reject direct component.** [class-path, attribute and method transforms](https://github.com/Farama-Foundation/HighwayEnv/blob/37c84a34cadcbfc17d61acf5196a89c380a56943/highway_env/envs/common/abstract.py#L397-L452) are flexible developer tools, whereas the application already uses [bounded Stress/Inspection schemas](https://github.com/EmotiveImpact/8ball/blob/4f31c6b40141990d0863d9375f47a7ad51863dfc/endstate/plan_review.py#L31-L49). Retain typed allowlists and stable IDs, not arbitrary upstream configuration. Likewise simulator observations/time advances are not external observations or elapsed real-world events.

Architecture/UX implication: show what was projected, changed, omitted, bounded and merely hypothesized; never let a clean API result, favorable rank or agreement badge imply authority or truth. All seven proposed benefits remain hypotheses until the owner chooses a bounded application-owned experiment.
