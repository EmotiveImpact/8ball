# ADR 0004: strengthen vision around selected courses and recoverable decisions

Date: 24 September 2026.

**Status:** adopted documentation direction under the owner's instruction to retain and evaluate valuable discoveries. Detailed scope/priorities remain owner-reviewable. This ADR does not approve a production release or new required version gates.

## Context

The recovered alpha.7 source distinguishes evidence, route alternatives, reviews and authority well. It does not yet define an explicit selected-course contract spanning the operator's choice and future changes. The existing emergence register already identifies outcome envelopes, freshness, knowledge acquisition, review burden and bounded search; those are refinements, not discoveries to rename as new features.

The later Draft Repair delivery record says the completed working tree was not recovered. Its reported code and test counts cannot be imported into this source's implementation state. The verified alpha.7 tree is `5c49a40395e6d22510a8895a90ddd2f759378efa`. This review adds documents and tracking only, plus documentation tests.

## Decision

Keep 8BALL as the fixer-facing situation room. Strengthen its vision to include an explicit mandate, a human-selected course, visible reconsideration reasons and recovery when analysis or plans fail. Strengthen ENDSTATE as a neutral evidence-linked planning and reconsideration engine, not an autonomous controller of people or an execution service.

Preserve all 55 prior discoveries and their original text. Append decision history where emphasis changes. Add EM-056 through EM-065 for distinct refinements, with hypotheses labelled as such. No new entry inherits an old completion tick merely because part of it resembles existing work.

Add four optional, unaccepted candidate/recovery tasks: B03-07, ES02-06, ES03-08 and B04-04. Existing required task IDs, required flags and statuses remain unchanged. Strengthen the definitions and acceptance examples for existing work without lowering any original gate.

## Rejected shortcuts

- Automatically choosing or changing a course because it ranks first.
- Preserving an approval merely because a heuristic says a change is small.
- Replacing the original target with a more achievable fallback without authorisation.
- Declaring global impossibility from a bounded catalogue or truncated search.
- Counting human-corrected output as unassisted model success.
- Treating a reported build or unavailable archive as reproducible implementation.
- Creating extra graphs, services or screens merely to give each insight a product name.
- Training on client corrections or exposing them across cases without permission.

## Consequences

The vision is stronger without expanding the current release checklist denominator. Recovered runtime source remains alpha.7; V0.2, model quality, native integration and secure agency acceptance stay open. Deliver the documentation patch as an exact-base overlay. When newer source is recovered, reconcile histories and task IDs rather than replacing it with this older runtime baseline.
